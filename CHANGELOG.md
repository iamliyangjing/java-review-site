# Changelog

## 1.0.0-beta.1

- Offline Windows desktop question bank backed by local SQLite.
- Original Chinese study prompts across 183 categories with per-question references.
- SM-2 review scheduling, custom questions, trash recovery, history, and JSON import/export.
- Optional manual Supabase backups with up to 10 restorable snapshots.
- Local database integrity checks and rolling backups.
- Unsigned Windows installer and portable build; no automatic updater or telemetry.

This is a Beta release. Windows may display an unsigned-app warning. Verify the downloaded executable against SHA256SUMS.txt before running it.
