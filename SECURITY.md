# Security policy

## Supported versions

Security fixes are made against the latest Beta or stable release on the default branch.

## Reporting a vulnerability

Please do not publish credentials, personal data, database backups, or an exploitable vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository when available. Otherwise contact the maintainers through the GitHub profile and include a concise reproduction, affected version, impact, and a safe way to follow up.

Do not include your question database, Supabase password, access token, or service-role key in a report. The app has no telemetry; diagnostic bundles are generated only when the user asks and should be reviewed before sharing.

We will acknowledge a report, assess impact, and coordinate a fix and disclosure timeline with the reporter.
